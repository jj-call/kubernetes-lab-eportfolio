# 🧩 Kubernetes Lab ePortfolio

Welcome! 👋  
This repository documents my hands-on journey learning **Kubernetes** by following *The Kubernetes Book (2025 Edition)* by Nigel Poulton.  

The goal of this ePortfolio is to demonstrate:
- My understanding of core Kubernetes concepts  
- Practical skills in deploying, managing, and securing containerized workloads  
- Continuous learning and collaboration with DevOps and AppSec engineers  

---

## 🧭 Objectives

- Learn and apply Kubernetes fundamentals (pods, deployments, services, etc.)  
- Understand how Kubernetes is used in production environments  
- Build confidence communicating with engineers and security teams  
- Showcase progress publicly through GitHub and GitHub Pages  

---

## 🧰 Environment Setup

- **OS:** Windows 11 (WSL 2 enabled)  
- **Container Runtime:** Docker Desktop with Kubernetes enabled  
- **CLI Tools:**  
  - `kubectl`  
  - `helm`  
  - `git`  
  - `minikube` (optional)  

Setup notes and configurations are documented in [`docs/ch01-setup.md`](./docs/ch01-setup.md).
